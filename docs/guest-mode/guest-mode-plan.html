ערך מיידי ללא חשבון · אכיפה אמיתית במסכים ובשרת · פרטיות כברירת מחדל

יושם, נפרס ואומת ידנית ואוטומטית · 20.07.2026
סטטוס ביצוע: חוזה ההרשאות, Optional JWT, מצב ה־session, שערי הפעולה והנתיבים, קהילה לקריאה בלבד, מועדפים ו־returnTo יושמו ונבדקו ידנית. 235 בדיקות backend, 32 בדיקות חוזה HTTP, build ו־mobile typecheck עברו. חיפוש מוגבל ל־30 בקשות בדקה ואומת בייצור.
נותר לפני שחרור: להעביר את ה־API ל־HTTPS באמצעות reverse proxy ותעודה. כרגע Nest חשוף ישירות בפורט 3000 ולכן אין להפעיל trust proxy; לאחר התקנת ה־proxy יש להגדיר trusted hops מצומצם ולאמת שוב את זיהוי ה־IP.

יעדים, מסעדות, בתי כנסת, מפה, ביקורות לקריאה ופרטי מניין בסיסיים.

החלטת מוצר: מועדפים מקומיים נשארים פתוחים לאורח. חשבון נדרש לסנכרון בין מכשירים, לא לשמירה במכשיר.

Optional JWT במניין בודד

מחובר מקבל isRegistered אמיתי; אורח מקבל false. אין לגשת ל־req.user.sub כשאין משתמש. token פגום שנשלח יידחה.

פרטיות מניינים

האורח רואה את מספר המשתתפים, לא את שמותיהם. בכל רשימות ופרטי המניין שם היוצר יוצג לאורח כשם פרטי + האות הראשונה של שם המשפחה; משתמש מחובר יכול לקבל שם מלא דרך Optional JWT.

במצב session במובייל

type SessionMode =
  | 'loading'
  | 'signedOut'
  | 'guest'
  | 'authenticated';

מצב יחיד מונע סתירה בין token לבין isGuest. התחברות מנקה דגל אורח; logout ו־forced logout עוברים ל־signedOut.

פתיחה←loading←signedOut / guest / authenticated

מסך ההתחברות

כפתור משני “המשך כאורח”, שמירה ב־AsyncStorage וניווט ל־tabs. להוסיף מחרוזות בעברית, אנגלית וצרפתית.

גאכיפה בשתי שכבות

Action guard

AuthPromptProvider + useRequireAuth() במסכים ציבוריים.

  • פתיחת טופס ביקורת
  • דיווח והצעת מקום
  • יצירה והרשמה למניין
  • כניסה לצ'אט מניין

השער מופיע לפני מילוי הטופס, לא רק בעת submit.

Route guard

חובה גם בכניסה דרך deep link, התראה או ניווט ישיר.

  • כל hosting
  • צ'אט מניין ואירוח
  • my-minyans
  • blocked-users ו־admin

לא מרנדרים מסך פרטי מאחורי modal.

saved.tsx נשאר פתוח: הוא מציג את המועדפים המקומיים של האורח באמצעות פרטי מסעדות ובתי כנסת מה־API הציבורי.
אירוח נשאר גלוי כטיזר: כניסת האירוח במסך היעד אינה נעלמת. לחיצת אורח מציגה ערך קצר וכפתורי הרשמה/התחברות, בלי לנווט למסך האירוח ובלי לטעון /hosting/*. Deep links והתראות עדיין נחסמים ב־route guard.

דמועדפים וסנכרון

אורח

קריאה וכתיבה רק ל־AsyncStorage. אין בקשות שקטות ל־/favorites במצב guest.

מחובר

סנכרון עם השרת. לאחר התחברות מבצעים union של המקומי והשרת, בלי למחוק מועדפי שרת. cache מקומי נשאר שימושי ל־offline.

החזרה להקשר לאחר התחברות

returnTo פנימי ובטוח צריך לשרוד login, register, verify-email ו־onboarding.

  • לאחר הצלחה חוזרים למסך המקורי.
  • הפעולה המקורית אינה מתבצעת אוטומטית ב־1.0; המשתמש לוחץ שוב.
  • URL חיצוני או route לא מאושר נדחים.
  • fallback: /(tabs).

ו401, refresh וחיפוש

Interceptor

  • 401 אנונימי: reject בלבד
  • 401 עם token: refresh פעם אחת
  • refresh נכשל: ניקוי session ו־signedOut
  • אין refresh לנתיבי auth

חיפוש חכם

  • 30 בקשות בדקה ל־POST /search — נפרס ואומת
  • תקציב LLM נפרד: 50 ניסיונות ביום
  • PM2 רץ בתהליך יחיד; בהרחבה נדרש מונה משותף
  • אין proxy כרגע; trusted proxy יוגדר רק לאחר Nginx
  • 429 ידידותי ו־retention גם לאורחים

זפרטיות ו־App Review

  • למפות שאילתה, מיקום, IP ולוגים שנוצרים בחיפוש אורח.
  • לא להבטיח “אורח אינו שומר מידע בשרת” לפני אימות.
  • לבדוק מחדש App Privacy עבור מיקום וחיפוש ללא חשבון.
  • לספק ל־App Review חשבון פעיל לבדיקת הפיצ'רים המוגנים.
  • ב־Review Notes להסביר שהתוכן הציבורי נגיש דרך “המשך כאורח”.
