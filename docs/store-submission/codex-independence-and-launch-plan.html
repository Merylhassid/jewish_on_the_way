Google Play

השרת העצמאי

Mobile App │ ▼ api.jewishontheway.com │ ▼ Hetzner CX23 ── Nginx ── NestJS/PM2 │ ├── Neon Frankfurt ├── Cloudinary ├── Google Maps/Places ├── Anthropic └── Gmail SMTP

בחירה

Hetzner CX23 בגרמניה — מתאים להשקה כאשר DB חיצוני. מחיר €5.49 לפני IPv4 ומס; עם Backup של 20% לתכנן כ־₪25–32 בחודש.

צ׳קליסט הקמה

  • חשבון Hetzner עם 2FA ו־SSH key
  • Ubuntu 24.04 LTS באזור גרמניה
  • משתמש sudo, ביטול סיסמת SSH, UFW, Fail2ban ועדכוני אבטחה
  • Node LTS, PM2, Nginx ו־Certbot
  • npm ci, Build ו־migrations
  • .env ידני עם הרשאות מצומצמות
  • Nginx reverse proxy עם WebSocket/WSS
  • PM2 startup + logrotate ל־90 יום
  • Hetzner Backup וניסוי שחזור
  • Health endpoint וניטור חיצוני

DNS ואתר

  • jewishontheway.com ו־www → Cloudflare Pages.
  • api.jewishontheway.com → Hetzner.
  • Let's Encrypt על ה־Origin וכל התעבורה HTTPS/WSS.
  • לעבור ב־Mobile למשתנה EXPO_PUBLIC_API_URL, לא IP קשיח.

למה פרויקט חדש?

  1. מאמת בעלות ו־Billing עצמאיים.
  2. מבטל את הסיסמה הישנה שנחשפה ב־Git.
  3. מצמצם Latency בין Backend בגרמניה למסד.

מעבר בטוח

  • Neon Organization ופרויקט Frankfurt בבעלותך
  • PostGIS ו־Role חדש לאפליקציה
  • חלון תחזוקה + pg_dump מוצפן
  • pg_restore + migrations
  • השוואת ספירות וישויות קריטיות
  • עדכון env ו־Smoke test מלא
  • pg_dump שבועי וניסוי שחזור

מסלול: Free מספיק ל־Closed Test. לפרודקשן, Launch טיפוסי סביב $15 לחודש נותן חלון שחזור עד 7 ימים ויותר מרווח.

אבטחה וסודות

דחוף: פרטי Neon מלאים קיימים בקובצי Git. בנוסף, כל סוד שהיה ב־.env על שרת המכללה נחשב נגיש למנהל השרת ויש להחליפו.

Rotation
