0.6 Google Sign-In — נדחה לגרסה עתידית

החלטה מאושרת: גרסה 1.0 תושק עם אימייל וסיסמה בלבד. נבדקו כל מסכי האימות; רק ב-login וב-register קיים קוד Google, ובשניהם ENABLE_GOOGLE_AUTH = false, ולכן הכפתור אינו מוצג. הקוד נשאר כבוי לצורך אפשרות הפעלה עתידית.
בהפעלה עתידית יידרשו Android client ID (עם SHA-1 של keystore ה-EAS), iOS client ID, התאמת backend audience וטיפול גם בסעיף 0.7.

0.7 Apple Sign-In — לא נדרש בגרסה 1.0

גרסה 1.0 אינה מציעה Google Sign-In או התחברות באמצעות ספק צד שלישי אחר, ולכן לא מוסיפים כרגע Sign in with Apple. אם Google יופעל בעתיד, ייבדקו מחדש דרישות החנות ויוגדרו המימוש וה-Capability הנדרשים.

0.8 פושים — נדחה לגרסה 1.1

החלטה מאושרת: גרסה 1.0 תושק ללא התראות Push. ENABLE_PUSH_NOTIFICATIONS = false מונע בקשת הרשאה ויצירת Push Token; כשל ברישום כבר מטופל כ-best-effort ואינו מפיל את האפליקציה.
הקוד נשמר להפעלה עתידית. בגרסה 1.1 יידרשו Firebase ו-google-services.json באנדרואיד, ו-APNs key דרך חשבון המפתח ב-iOS.

0.9 פרטיות ושמירת לוגי אבטחה — מוכן בקוד, דורש הגדרת שרת בפריסה

  • אירועי Audit אינם שומרים אימייל קריא; אירועים רגילים נשמרים עם userId בלבד
  • ניסיונות כניסה ובקשות איפוס סיסמה נשמרים עם HMAC-SHA256 email fingerprint
  • המפתח המועדף הוא AUDIT_FINGERPRINT_SECRET; fallback ל-JWT_SECRET קיים לתאימות בלבד
  • AuditService מסיר שדה email גולמי אם יועבר בטעות בעתיד
  • כתובות אימייל גלויות וטוקן איפוס הוסרו גם מלוגי MailService ו-AuthService; שגיאת איפוס מזוהה באמצעות userId בלבד

צ'קליסט חד-פעמי בפריסה:

  1. להגדיר AUDIT_FINGERPRINT_SECRET קבוע וסודי בפרודקשן
  2. pm2 install pm2-logrotate
  3. pm2 set pm2-logrotate:rotateInterval "0 0 * * *"
  4. pm2 set pm2-logrotate:retain 90
  5. pm2 set pm2-logrotate:compress true
  6. לאמת באמצעות pm2 conf; הלוגים הקיימים ייצאו מהמחזור אוטומטית ואין למחוק אותם ידנית
